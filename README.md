# Aula1_POO
Os 6 exercicios da aula 1 de POO

## O que esta sendo usado:
1. Todos são feitos em Java na IDE IntelliJ
2. Uso de tradutor google para entendimento dos erros (interpretação do erros complexos por meio do ChatGPT = ex: 3)

#### O que já foi aprendido:
1. Uso do For no ex: 1,2,3
2. Uso do Scanner todos*
3. Declaração de variaveis locais em todos
4. Uso do tipo de dados int (ex: 1,2,3), float(ex: 2,3,4), double(ex: 4,5,6)*** e do String(ex: 5,6)
5. Uso do "System.exit(0);" para termino do sistema (ex: 3)
6. Uso do if simples no ex: 3
7. Uso das operações basicas (ex: 4,5,6)
8. Uso Do-While (ex: 5,6)**
9. Uso do resposta.equalsIgnoreCase("sim") para verificação da resposta do usuario no Do para inicio do While (ex: 5,6)****
10. Uso de "teste de print" para verificação de erros logicos

*Só é preciso usar 1 por class
**O Do tem o codigo e o While pode ter só a mensagem final e a conclusão
***Melhor do que usar o float
****Verifica a resposta sendo maiuscula ou minuscula
